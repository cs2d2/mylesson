## 1. 状态变量与状态向量的区别

**状态变量**：能完全确定系统状态的一组最少变量中的**每一个**，记作 $x_1(t),x_2(t),\dots,x_n(t)$，其中 $n$ 为系统的阶数。它们是**标量**，单独拿出一个，只能描述系统的一个侧面。

**状态向量**：把这 $n$ 个状态变量按固定次序排列成的一个整体，记作

$$\mathbf{x}(t)=\begin{bmatrix}x_1(t)\\ x_2(t)\\ \vdots\\ x_n(t)\end{bmatrix}\in\mathbb{R}^{n}$$

它是一个 **n 维列向量**，在 $t$ 时刻唯一地描述系统的全部状态，对应状态空间中的一个点。

| 对比项 | 状态变量 | 状态向量 |
| --- | --- | --- |
| 本质 | 单个标量 | n 个标量组成的整体 |
| 数量 | 共 n 个 | 只有 1 个（n 维） |
| 记号 | $x_i(t),\ i=1,2,\dots,n$ | $\mathbf{x}(t)=\left[x_1(t),\ x_2(t),\ \dots,\ x_n(t)\right]^{\mathrm{T}}$ |
| 描述能力 | 单个只能反映系统的一个侧面 | 完整描述系统在 $t$ 时刻的状态 |
| 关系 | 是状态向量的分量 | 由全部状态变量按固定次序排成 |

一句话：**状态变量是“分量”，状态向量是“整体”**——状态向量由这 n 个状态变量组成，其中任何一个分量发生变化，状态向量就随之改变。

## 2. R、L、C 是线性元件

电路里的三个基本元件——电阻 R、电容 C、电感 L——都是**线性元件**，它们的端口关系如下：

| 元件 | 端口关系（时域） | 关系类型 |
| --- | --- | --- |
| 电阻 R | $u_R(t)=R\,i_R(t)$ | 代数关系 |
| 电容 C | $u_C(t)=\dfrac{1}{C}\displaystyle\int_{-\infty}^{t}i_C(\tau)\,\mathrm{d}\tau$ | 积分关系 |
| 电感 L | $u_L(t)=L\,\dfrac{\mathrm{d}i_L(t)}{\mathrm{d}t}$ | 微分关系 |

**电容上的电压**（积分关系：电压 = 电流对时间的积分）：

$$u_C(t)=\frac{1}{C}\int_{-\infty}^{t}i_C(\tau)\,\mathrm{d}\tau=u_C(0)+\frac{1}{C}\int_{0}^{t}i_C(\tau)\,\mathrm{d}\tau$$

即把流过电容的电流 $i_C$ 作为输入，电容电压 $u_C$ 就是它的积分（再叠加上初始电压 $u_C(0)$）。若从零初始状态起算，简化为 $u_C(t)=\frac{1}{C}\int_0^t i_C\,\mathrm{d}\tau$。

**电感上的电压**（微分关系：电压 = 电流对时间的变化率）：

$$u_L(t)=L\,\frac{\mathrm{d}i_L(t)}{\mathrm{d}t}$$

即把流过电感的电流 $i_L$ 作为输入，电感电压 $u_L$ 与电流的变化率成正比，比例系数就是电感量 $L$。

（两种形式可以互相转换：微分与积分互为逆运算，例如在零初始条件下由 $u_L=L\frac{\mathrm{d}i_L}{\mathrm{d}t}$ 反解，即得 $i_L(t)=\frac{1}{L}\int_0^t u_L(\tau)\,\mathrm{d}\tau$。）

### 为什么它们是线性元件：齐次性 + 叠加性

一个元件（或系统）称为**线性**的，当且仅当它的输入输出关系同时满足下面两条。设输入 $x(t)$、响应 $y(t)$：

| 性质 | 数学表述 | 物理含义 |
| --- | --- | --- |
| 齐次性（比例性） | $x(t)\to y(t)\;\Longrightarrow\;k\,x(t)\to k\,y(t)$ | 输入放大 k 倍，响应也放大 k 倍 |
| 叠加性（可加性） | $x_1(t)+x_2(t)\to y_1(t)+y_2(t)$ | 多个输入共同作用的响应 = 各自单独作用响应之和 |
| 线性 | 两者同时成立：$k_1x_1+k_2x_2\to k_1y_1+k_2y_2$ | 才可以用叠加原理分析电路 |

**在电容上（输入电流 $i_C$，输出电容电压 $u_C$）**

- 齐次性：若 $i_C(t)\to u_C(t)$，则 $k\,i_C(t)\to\frac{1}{C}\int k\,i_C\,\mathrm{d}\tau=k\,u_C(t)$。即给电容的充电电流放大 k 倍，电容电压也放大 k 倍。
- 叠加性：若 $i_C=i_{C1}+i_{C2}$，则 $\frac{1}{C}\int(i_{C1}+i_{C2})\,\mathrm{d}\tau=u_{C1}+u_{C2}$。即两个电流源同时作用产生的电容电压，等于它们分别作用产生的电压之和。

**在电感上（输入电流 $i_L$，输出电感电压 $u_L$）**

- 齐次性：若 $i_L(t)\to u_L(t)$，则 $k\,i_L(t)\to L\frac{\mathrm{d}(k\,i_L)}{\mathrm{d}t}=k\,L\frac{\mathrm{d}i_L}{\mathrm{d}t}=k\,u_L(t)$。即电感电流放大 k 倍，电感电压也放大 k 倍。
- 叠加性：若 $i_L=i_{L1}+i_{L2}$，则 $L\frac{\mathrm{d}(i_{L1}+i_{L2})}{\mathrm{d}t}=u_{L1}+u_{L2}$。即两个电流源同时作用产生的电感电压，等于它们分别作用产生的电压之和。

**根本原因**：积分运算 $\int(\cdot)\,\mathrm{d}\tau$ 与微分运算 $\frac{\mathrm{d}}{\mathrm{d}t}$ 都是线性运算（$\int(kx)\,\mathrm{d}\tau=k\int x\,\mathrm{d}\tau$、$\frac{\mathrm{d}(x_1+x_2)}{\mathrm{d}t}=\frac{\mathrm{d}x_1}{\mathrm{d}t}+\frac{\mathrm{d}x_2}{\mathrm{d}t}$），乘常数 $\frac{1}{C}$、$L$ 以及电阻的 $u=Ri$ 同样是线性运算——所以 R、L、C 的端口关系都满足齐次性与叠加性，都是线性元件。

> 顺带联系上一小点：电容电压 $u_C$ 和电感电流 $i_L$ 都与储能有关、且不能突变，因此在状态变量法里最常被选作状态变量。

## 3. 传递函数 $G(s)$ 的求解公式与建模的第一性原理

### 由状态空间模型求传递函数

设线性定常系统的状态空间模型为

$$\dot{\mathbf{x}}=A\mathbf{x}+B\mathbf{u},\qquad \mathbf{y}=C\mathbf{x}+D\mathbf{u}$$

在**零初始条件**下对两式取拉普拉斯变换（记 $\mathcal{L}\{\dot{\mathbf{x}}\}=sX(s)$）：

$$sX(s)=AX(s)+BU(s)\;\Longrightarrow\;(sI-A)X(s)=BU(s)\;\Longrightarrow\;X(s)=(sI-A)^{-1}BU(s)$$

$$Y(s)=CX(s)+DU(s)=\left[C(sI-A)^{-1}B+D\right]U(s)$$

于是传递函数为

$$\boxed{\,G(s)=\frac{Y(s)}{U(s)}=C(sI-A)^{-1}B+D\,}$$


**几点说明**

- 分母 $\det(sI-A)$ 就是系统的特征多项式，它的根（即 $A$ 的特征值）就是系统的极点；分子的根是零点。
- $D$ 是直接传递项（前馈项）：$D=0$ 时 $G(s)$ 为严格真，分子阶数低于分母阶数；$D\neq 0$ 时存在直接馈通。
- 使用前提：**线性定常**系统 + **零初始条件**。若初始状态不为零，输出中还要加上零输入响应对应的项。
- 单输入单输出时 $G(s)$ 是一个标量分式；多输入多输出时 $G(s)$ 是矩阵，其中 $G_{ij}(s)$ 表示第 $j$ 个输入到第 $i$ 个输出的传递函数。
- 传递函数只描述**输入输出**关系，不反映内部状态：若发生零极点相消，被消去的那部分状态（不可控或不可观测的部分）在 $G(s)$ 里是看不到的。

### 建模的第一性原理

**第一性原理**指的是：不依赖实验数据做拟合（黑箱建模），而是从最基本的物理定律出发，直接推导出系统的数学模型。这样得到的方程中每个参数都有明确的物理意义，适用范围也更广。

| 系统类型 | 依据的第一性原理 | 列写出的方程 |
| --- | --- | --- |
| 电路 | 基尔霍夫电流定律 KCL（电荷守恒）：节点上电流的代数和为零<br>基尔霍夫电压定律 KVL（能量守恒）：回路中电压的代数和为零 | 节点电流方程、回路电压方程 |
| 机械平动 | 牛顿第二定律（动量守恒）$F=ma$ | $m\ddot{x}=\sum F$ |
| 机械转动 | 转动定律（角动量守恒）$T=J\ddot{\theta}$ | $J\ddot{\theta}=\sum T$ |
| 一般系统 | 质量守恒、能量守恒、动量守恒 | 微分方程 |

**建模步骤**

1. 明确研究对象，确定输入量与输出量。
2. 选取状态变量：优先取储能元件上的量——电容电压 $u_C$、电感电流 $i_L$（机械系统则取位移与速度）。
3. 用第一性原理列写方程：对含电容的节点列 KCL，对含电感的回路列 KVL，并代入元件的端口关系（见第 2 小点）。
4. 消去中间变量，整理成标准状态空间形式 $\dot{\mathbf{x}}=A\mathbf{x}+B\mathbf{u}$、$\mathbf{y}=C\mathbf{x}+D\mathbf{u}$。
5. 需要输入输出描述时，用上面的公式求出 $G(s)=C(sI-A)^{-1}B+D$。

> 两条路径的分工：第一性原理 → 状态空间模型（内部描述，保留全部状态信息）；状态空间模型 → $G(s)$（外部描述，只反映输入输出关系）。

## 4. 由框图建立 $\dot{x}(t)$ 与 $y(t)$：状态变量的选取

### 例子：两个惯性环节 + 一个积分环节 + 比例负反馈

框图如下，每个动态环节的输出都标出了所选的状态变量：

![[图片库/框图建模-状态变量选取.png]]

三个动态环节与反馈支路：

| 环节 | 传递函数 | 输入 → 输出 |
| --- | --- | --- |
| 惯性环节 1 | $G_1(s)=\dfrac{K_1}{T_1s+1}=\dfrac{2}{0.5s+1}$ | $e\to x_1$ |
| 惯性环节 2 | $G_2(s)=\dfrac{K_2}{T_2s+1}=\dfrac{2}{s+1}$ | $x_1\to x_2$ |
| 积分环节 | $G_3(s)=\dfrac{1}{s}$ | $x_2\to x_3$ |
| 反馈支路 | 比例系数 $H=1$ 的负反馈 | 比较点 $e(t)=u(t)-Hy(t)$ |

三个一阶环节串联，故系统阶数 $n=1+1+1=3$。

### 状态变量的选取原则

| 原则 | 含义 | 本例体现 |
| --- | --- | --- |
| ① 个数等于阶数 | 状态变量个数必须等于系统阶数 $n$：少了无法确定系统未来的行为，多了则线性相关、方程不独立 | $n=3$，故取 3 个 |
| ② 取动态环节的输出 | 每个含记忆的环节（惯性、积分、振荡等）输出各取一个状态变量 | ①②③ 三个环节的输出 |
| ③ 相互独立 | 各状态变量必须线性无关，不能由其他状态变量线性表示 | 三个变量分处不同环节，彼此独立 |
| ④ 是最小一组 | 既完备又最少，能完全描述系统在 $t$ 时刻的状态 | 恰好 3 个，不多不少 |

> 注意：纯比例环节是代数关系，不引入新的状态变量——本例的比例反馈支路 $H$ 就只在比较点体现为 $e=u-Hy$。若反馈支路中再串入惯性环节或积分环节，阶数与状态变量个数都要相应增加。

本例选取：

- $x_1(t)$ = 惯性环节 1 的输出
- $x_2(t)$ = 惯性环节 2 的输出
- $x_3(t)$ = 积分环节的输出（也就是输出 $y$）

### 逐个环节求导的过程

做法：把每个环节的 $s$ 域关系还原成微分方程，再用拉普拉斯变换的微分性质 $sX(s)\leftrightarrow\dot{x}(t)$ 解出该状态变量的导数。

**① 惯性环节 1**（输入 $e$，输出 $x_1$）

$$\frac{X_1(s)}{E(s)}=\frac{2}{0.5s+1}\;\Longrightarrow\;(0.5s+1)X_1(s)=2E(s)$$

$$0.5\,\dot{x}_1+x_1=2e\;\Longrightarrow\;\dot{x}_1=-\frac{1}{T_1}x_1+\frac{K_1}{T_1}e=-2x_1+4e$$

**② 惯性环节 2**（输入 $x_1$，输出 $x_2$）

$$\frac{X_2(s)}{X_1(s)}=\frac{2}{s+1}\;\Longrightarrow\;(s+1)X_2(s)=2X_1(s)$$

$$\dot{x}_2+x_2=2x_1\;\Longrightarrow\;\dot{x}_2=-x_2+2x_1$$

**③ 积分环节**（输入 $x_2$，输出 $x_3$）

$$\frac{X_3(s)}{X_2(s)}=\frac{1}{s}\;\Longrightarrow\;sX_3(s)=X_2(s)\;\Longrightarrow\;\dot{x}_3=x_2$$

**④ 输出关系**：输出直接取自积分环节的输出，因此

$$y(t)=x_3(t)$$

**⑤ 消去中间变量**：比较点给出 $e(t)=u(t)-Hy(t)=u(t)-x_3(t)$，代回 ① 式

$$\dot{x}_1=-2x_1+4(u-x_3)=-2x_1-4x_3+4u$$

### 汇总成标准形式 $\dot{\mathbf{x}}=A\mathbf{x}+Bu$、$y=C\mathbf{x}+Du$

$$\begin{bmatrix}\dot{x}_1\\ \dot{x}_2\\ \dot{x}_3\end{bmatrix}=\begin{bmatrix}-2&0&-4\\ 2&-1&0\\ 0&1&0\end{bmatrix}\begin{bmatrix}x_1\\ x_2\\ x_3\end{bmatrix}+\begin{bmatrix}4\\ 0\\ 0\end{bmatrix}u$$

$$y=\begin{bmatrix}0&0&1\end{bmatrix}\begin{bmatrix}x_1\\ x_2\\ x_3\end{bmatrix}+0\cdot u$$

$$A=\begin{bmatrix}-2&0&-4\\ 2&-1&0\\ 0&1&0\end{bmatrix},\quad B=\begin{bmatrix}4\\0\\0\end{bmatrix},\quad C=\begin{bmatrix}0&0&1\end{bmatrix},\quad D=0$$

可以看到负反馈的痕迹：$u$ 前的系数是 $+4$，而 $x_3$ 前的系数是 $-4$，正好相差一个 $-H$。

### 两个检查，确认没选错

- **阶数检查**：$\det(sI-A)=s(s+1)(s+2)+8=s^3+3s^2+2s+8$，是 3 次多项式，与 $n=3$ 相符。
- **传递函数检查**：由框图直接求闭环传递函数 $G(s)=\dfrac{G_1G_2G_3}{1+HG_1G_2G_3}=\dfrac{8}{s(s+1)(s+2)+8}$，与用第 3 小点的公式 $C(sI-A)^{-1}B+D$ 算出的结果完全一致，说明状态变量的选取与所列方程都是正确的。
