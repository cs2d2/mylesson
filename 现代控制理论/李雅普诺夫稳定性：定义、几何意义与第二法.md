# 李雅普诺夫稳定性：定义、几何意义与第二法

创建日期：2026-10-19

## 1. 稳定性到底在说什么

考虑系统 $\dot x=f(x,t)$，平衡点 $x_e$ 满足 $f(x_e,t)=0$。所谓"系统稳定"，关心的不是某一条特定轨迹，而是：**当初始状态被扰动到 $x_e$ 附近时，后面的轨迹会不会跑远。**

这里有三种层次，很多人容易混为一谈：

| 说法 | 严格含义 |
| --- | --- |
| **稳定** | 初始偏差足够小时，之后的状态偏差**一直**被限制在给定范围内（不一定回到原点） |
| **渐近稳定** | 稳定 + 随着 $t\to\infty$，状态**最终回到** $x_e$ |
| **不稳定** | 无论把初始扰动限制得多小，总有一条轨迹会跑出给定范围 |

所以"受扰后能不能回到原位"这个直觉，严格对应的是**渐近稳定**；而"稳定"只要求"不跑远"——它可能绕着 $x_e$ 一直振荡（比如无阻尼振子），永远不回到原位。不稳定的情况则连"不跑远"都做不到。

## 2. 稳定的数学定义

平衡点 $x_e$ 是**李雅普诺夫意义下稳定**的，如果：对任意给定的 $\varepsilon>0$，都存在一个 $\delta(\varepsilon,t_0)>0$，使得只要初始状态满足

$$\lVert x_0-x_e\rVert<\delta(\varepsilon,t_0),$$

就有对一切 $t\ge t_0$

$$\lVert x(t;x_0,t_0)-x_e\rVert<\varepsilon.$$

写成逻辑式：

$$\boxed{\forall\varepsilon>0,\ \exists\,\delta(\varepsilon,t_0)>0:\quad \lVert x_0-x_e\rVert<\delta\ \Rightarrow\ \lVert x(t)-x_e\rVert<\varepsilon,\quad\forall t\ge t_0}$$

几个要点：

- **顺序不能反**：先给定 $\varepsilon$（允许的后续偏差），再去找 $\delta$（允许的初始扰动）。也就是说 **$\delta$ 是由 $\varepsilon$ 反推出来的**，而且一般 $\delta\ll\varepsilon$。
- $\delta$ 一般还与初始时刻 $t_0$ 有关；若存在与 $t_0$ 无关的 $\delta$，则称**一致稳定**。
- 有的教材把 $\varepsilon$ 写成 $\xi$，把式子写成"$\lVert x_0-x_e\rVert$ 小于由 $t_0$ 和 $\xi$ 确定的函数值 $\delta(\xi,t_0)$，且对任意 $\xi>0$ 该函数取正值"——说的是同一件事。

### 几何意义（图 ①）

以 $x_e$ 为圆心画两个同心圆：半径 $\delta$ 的**初始扰动圆**、半径 $\varepsilon$ 的**允许偏差圆**。

- 只要起点落在 $\delta$ 圆内，整条轨迹就始终留在 $\varepsilon$ 圆内 → **稳定**；
- 只要存在一条从 $\delta$ 圆内出发、却跑出 $\varepsilon$ 圆的轨迹 → **不稳定**。

## 3. 渐近稳定与不稳定

**渐近稳定**：在稳定的基础上，还要求

$$\lim_{t\to\infty}\lVert x(t)-x_e\rVert=0.$$

**不稳定**：存在某个 $\varepsilon>0$，使得对任意 $\delta>0$ 都能找到初始点 $x_0$（满足 $\lVert x_0-x_e\rVert<\delta$）和某个时刻 $t\ge t_0$，使

$$\lVert x(t)-x_e\rVert\ge\varepsilon.$$

![[图片库/李雅普诺夫稳定性-两个同心圆与能量函数.png]]

左图是定义本身：蓝色轨迹起点在 $\delta$ 圆内、全程不出 $\varepsilon$ 圆（还越绕越靠里，是渐近稳定）；红色轨迹起点同样在 $\delta$ 圆内，却一路螺旋向外穿出 $\varepsilon$ 圆，所以不稳定。

右图把"能量" $V$ 随时间的变化画在一起：渐近稳定时 $V\to0$（蓝），只是稳定时 $V$ 保持有界但不趋零（橙，典型的等幅振荡），不稳定时 $V$ 越来越大（红）。

## 4. 李雅普诺夫第二法：不解方程，看能量

第一法是"解出轨迹再判断"，但非线性系统往往解不出来。第二法（直接法）换了个思路：**构造一个标量函数 $V(x)$ 当作"能量"，看它沿轨迹是增还是减。**

### 4.1 几个术语

- $V(x)$ **正定**：$V(x_e)=0$，且 $x\ne x_e$ 时 $V(x)>0$；
- $V(x)$ **负定 / 半负定**：$-V$ 正定 / 半正定（半正定允许取 0）；
- $\dot V$：$V$ 沿轨迹对时间的导数，

$$\dot V(x)=\frac{\partial V}{\partial x}f(x,t)=\nabla V(x)^{\mathrm T}f(x,t).$$

### 4.2 判据

| 条件 | 结论 |
| --- | --- |
| $V$ 正定，$\dot V\le0$（半负定） | $x_e$ **稳定** |
| $V$ 正定，$\dot V<0$（负定） | $x_e$ **渐近稳定** |
| $V$ 正定、$\dot V<0$，且 $V(x)\to\infty$（当 $\lVert x\rVert\to\infty$） | **全局渐近稳定** |
| $V$ 正定，$\dot V>0$（在 $x_e$ 的某邻域内） | $x_e$ **不稳定** |

### 4.3 "径向无界"为什么是全局性的关键

$V(x)\to\infty$（当 $\lVert x\rVert\to\infty$）称为**径向无界**。它的作用是保证 $V$ 的等值线是**闭合曲线**、把状态"围在有限范围内"：只要 $V$ 不断下降，轨迹就只能待在越来越小的等高线圈里，不可能跑到无穷远。少了这一条，只能得到局部结论。

几何上可以把 $V$ 想成一口碗：$V$ 是高度，$\dot V<0$ 表示状态总在往低处走，最后滑到碗底 $x_e$。径向无界 = 这口碗在四周都向上翘、没有"通到外面"的缺口。

## 5. $\dot V$ 只是半负定时，多出来的那条要求

如果只能证明 $\dot V\le0$（允许取等号），那么 $V$ 可能在某个高度上停住不再下降——这时只能断定**稳定**，不能断定**渐近稳定**。要补上渐近性，需要加一条**额外要求**（这就是 LaSalle 不变原理，也称 Krasovskii–LaSalle 定理）：

> **集合 $\{\,x:\dot V(x)=0\,\}$ 中，除了平衡点 $x_e$ 之外，不能包含系统的任何整条轨迹。**

换句话说：满足 $\dot V=0$ 的那些点，只是"瞬时能量不变化"，**不能是一条真实解**；如果系统"一直待在 $\{\dot V=0\}$ 里"的唯一办法是停在 $x_e$，那么 $V$ 就只能一路降到 0，从而渐近稳定。

### 5.1 反例：条件不满足时，结论确实不成立

无阻尼振子

$$\dot x_1=x_2,\qquad \dot x_2=-x_1,\qquad V=x_1^2+x_2^2$$

$$\dot V=2x_1\dot x_1+2x_2\dot x_2=2x_1x_2+2x_2(-x_1)=0.$$

$\dot V\equiv0$ 处处成立，于是 $\{\dot V=0\}$ 就是整个状态空间——每条轨迹都躺在里面。它确实满足 $\dot V\le0$，但系统只是**等幅振荡**（能量守恒），并不渐近稳定。这说明"$\dot V\le0$"这条半负定的判据不能直接升级成渐近稳定，必须检查那条额外要求。

### 5.2 正例：条件成立时，可以升格为渐近稳定

带阻尼的单摆

$$\dot x_1=x_2,\qquad \dot x_2=-\sin x_1-x_2,\qquad V=\tfrac12x_2^2+(1-\cos x_1)$$

（$V$ 是"动能 + 势能"，正定，且在原点附近径向无界）

$$\dot V=x_2\dot x_2+\sin x_1\cdot\dot x_1=x_2(-\sin x_1-x_2)+\sin x_1\cdot x_2=-x_2^2\le0.$$

$\dot V$ 只是半负定，但看 $\{\dot V=0\}=\{x_2=0\}$：要在 $x_2\equiv0$ 上停留，必须有 $\dot x_1=x_2=0$（所以 $x_1$ 不变）且 $\dot x_2=-\sin x_1=0$（所以 $x_1=k\pi$）。也就是说，能一直待在 $\{\dot V=0\}$ 里的轨迹只有那些平衡点本身，没有别的整条轨迹——条件满足，因此单摆是**渐近稳定**的。

## 6. 完整算例：用第二法判断稳定性

系统

$$\dot x_1=-x_1+x_2,\qquad \dot x_2=-x_1-x_2,$$

平衡点为 $x_e=0$。

**第一步：选能量函数**

先取最简单的二次型

$$V(x)=x_1^2+x_2^2.$$

- 正定：$x\ne0$ 时 $V>0$，$V(0)=0$ ✓
- 径向无界：$\lVert x\rVert\to\infty$ 时 $V\to\infty$ ✓

**第二步：沿轨迹求导**

$$\dot V=2x_1\dot x_1+2x_2\dot x_2=2x_1(-x_1+x_2)+2x_2(-x_1-x_2)=-2x_1^2+2x_1x_2-2x_1x_2-2x_2^2$$

交叉项 $+2x_1x_2$ 与 $-2x_1x_2$ 正好抵消：

$$\dot V=-2(x_1^2+x_2^2)=-2V<0,\qquad\forall x\ne0.$$

**第三步：下结论**

$\dot V$ 负定 → **渐近稳定**；$V$ 又径向无界 → **全局渐近稳定**。

而且这里还能顺便看出收敛速度：$\dot V=-2V$ 是一阶线性微分方程，解出

$$V(t)=V(0)\,e^{-2t}\;\Longrightarrow\;\lVert x(t)\rVert=\lVert x(0)\rVert\,e^{-t},$$

状态按 $e^{-t}$ 的速率收敛到原点（与矩阵特征值 $-1\pm j$ 的实部一致）。

**第四步（可选）：用李雅普诺夫方程系统求解**

对线性系统 $\dot x=Ax$，若取 $V=x^{\mathrm T}Px$，则

$$\dot V=x^{\mathrm T}(A^{\mathrm T}P+PA)x.$$

于是可以反过来"解方程"找 $P$：给定正定矩阵 $Q$（常取单位阵），解

$$A^{\mathrm T}P+PA=-Q.$$

本例 $A=\begin{bmatrix}-1&1\\-1&-1\end{bmatrix}$，取 $Q=I$，解得 $P=\tfrac12 I\succ0$（正定），说明系统渐近稳定——与上面取 $V=x_1^2+x_2^2$ 只差一个常数倍，结论一致。

**第五步：几何验证**

![[图片库/李雅普诺夫第二法-算例相图.png]]

$V=x_1^2+x_2^2$ 的等值线是同心圆。图里的轨迹都螺旋着往原点收敛，而且**总是向内穿过更小的等值圆**——这就是 $\dot V<0$ 的几何含义：能量单调下降。

## 7. 补充例子：完整解一次 $A^{\mathrm T}P+PA=-Q$

前面那个算例里恰好解出 $P=\tfrac12I$，是特殊情形。换一个一般些的系统，把"解李雅普诺夫方程"真正算一遍。

**系统**：$\dot x=Ax$，其中

$$A=\begin{bmatrix}0&1\\-2&-3\end{bmatrix}.$$

（它的特征值是 $-1$、$-2$，本来就是渐近稳定的，正好用来检验方法。）

**第一步：设未知的对称矩阵**

因为 $A^{\mathrm T}P+PA$ 一定是对称阵，所以 $P$ 只取对称形式，三个未知数 $p,q,r$：

$$P=\begin{bmatrix}p&q\\q&r\end{bmatrix}.$$

**第二步：代入并展开**

$$A^{\mathrm T}=\begin{bmatrix}0&-2\\1&-3\end{bmatrix},$$

$$
\begin{aligned}
A^{\mathrm T}P+PA
&=\begin{bmatrix}0&-2\\1&-3\end{bmatrix}\begin{bmatrix}p&q\\q&r\end{bmatrix}
+\begin{bmatrix}p&q\\q&r\end{bmatrix}\begin{bmatrix}0&1\\-2&-3\end{bmatrix}\\[4pt]
&=\begin{bmatrix}-2q&-2r\\p-3q&q-3r\end{bmatrix}
+\begin{bmatrix}-2q&p-3q\\-2r&q-3r\end{bmatrix}\\[4pt]
&=\begin{bmatrix}-4q&p-3q-2r\\p-3q-2r&2q-6r\end{bmatrix}.
\end{aligned}
$$

**第三步：令它等于 $-Q=-I$，得到三个方程**

$$-4q=-1,\qquad p-3q-2r=0,\qquad 2q-6r=-1.$$

（矩阵是对称的，非对角元在两个位置出现同样的式子，所以三个未知数只需要三个独立方程。）

**第四步：解方程组**

$$q=\frac14,\qquad 2\times\frac14-6r=-1\ \Rightarrow\ r=\frac14,\qquad p=3q+2r=\frac34+\frac12=\frac54.$$

所以

$$P=\begin{bmatrix}\frac54&\frac14\\[2pt]\frac14&\frac14\end{bmatrix}=\frac14\begin{bmatrix}5&1\\1&1\end{bmatrix}.$$

**第五步：用 Sylvester 判据检查正定性**

- 一阶主子式：$p=\frac54>0$ ✓
- 二阶主子式：$\det P=\frac54\cdot\frac14-\left(\frac14\right)^2=\frac{5-1}{16}=\frac14>0$ ✓

所以 $P\succ0$，$V=x^{\mathrm T}Px$ 正定。又因为 $Q=I\succ0$，沿轨迹

$$\dot V=x^{\mathrm T}(A^{\mathrm T}P+PA)x=-x^{\mathrm T}Qx=-(x_1^2+x_2^2)<0,$$

负定 → **渐近稳定**，与特征值 $-1,-2$ 的结论一致。

**第六步：写出具体的 $V$**

$$V=x^{\mathrm T}Px=\frac54x_1^2+2\cdot\frac14x_1x_2+\frac14x_2^2=\frac54x_1^2+\frac12x_1x_2+\frac14x_2^2.$$

注意它**带交叉项**——这正是为什么要解方程：对一般的 $A$，随手取 $V=x_1^2+x_2^2$ 往往不满足李雅普诺夫方程（算出来的 $\dot V$ 会有交叉项、判不了定号），必须解出与 $A$ 匹配的 $P$。

**关于 $Q$ 的选取**

- $Q$ 只要**正定**即可（最常用 $I$）。换一个 $Q$ 会解出不同的 $P$，但"是否渐近稳定"的结论不变。
- 对线性系统：$A^{\mathrm T}P+PA=-Q$ 存在唯一正定解 $P\Longleftrightarrow A$ 的全部特征值实部为负（即渐近稳定）。所以它本身就是一个**稳定性判据**（李雅普诺夫方程法）。
- 若解出的 $P$ 不是正定，或根本解不出正定解，说明系统不是渐近稳定的。
- 编程实现：MATLAB 用 `lyap(A', Q)`（它解的是 $AX+XA^{\mathrm T}+Q=0$）；Python 用 `scipy.linalg.solve_lyapunov(A.T, -Q)`。上面这个例子的数值验证结果为

$$P=\begin{bmatrix}1.25&0.25\\0.25&0.25\end{bmatrix},\qquad \lambda(P)=\{0.191,\ 1.309\}>0,$$

残差 $\lVert A^{\mathrm T}P+PA+Q\rVert_{\max}\approx2\times10^{-16}$，与手算完全一致。

## 8. 小结

| 要达到的结论 | 需要的条件 |
| --- | --- |
| 稳定 | $V$ 正定，$\dot V\le0$ |
| 渐近稳定 | $V$ 正定，$\dot V<0$；或 $\dot V\le0$ 且 $\{\dot V=0\}$ 中除 $x_e$ 外没有整条轨迹（LaSalle） |
| 全局渐近稳定 | 在渐近稳定的基础上，$V$ 径向无界 |
| 不稳定 | $V$ 正定，$\dot V>0$（局部） |

用第二法解题的固定套路：**写方程 → 选 $V$（二次型或物理能量）→ 求 $\dot V$ → 判定号 → 检查径向无界 / LaSalle 条件 → 结论**。

对**线性系统**还有一条更机械的路：直接解 $A^{\mathrm T}P+PA=-Q$（$Q\succ0$），看解出的 $P$ 是否正定——这就把"找能量函数"变成了"解一个线性方程组"（见第 7 节）。
