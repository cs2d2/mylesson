# 计算图、前向传播与反向传播

创建日期：2026-09-21

## 一张图看懂

![[图片库/计算图-前向传播与反向传播.png]]

## 1. 计算图（computational graph）

把计算过程画成一张**有向图**：

- **节点**：变量或运算
- **边**：数据的流动方向，也就是计算的先后顺序

本例的计算图：$x$ 与 $w$ 经乘法节点得到 $u=wx$，$u$ 与偏置 $b$ 经加法节点得到 $z=u+b$，$z$ 再和标签 $y$ 一起送入损失节点，得到 $L=\frac{1}{2}(z-y)^{2}$。其中 $x,w,b,y$ 是叶子节点（输入），$L$ 是根节点（输出）。

意义：只要把计算写成图，求导就可以交给程序自动完成——这正是 PyTorch、TensorFlow 自动微分（autograd）的基础。

## 2. 前向传播（forward propagation）

从叶子往根，**从左往右**逐个节点代入数值：

$$u=w\,x=3\times 2=6$$

$$z=u+b=6+1=7$$

$$L=\tfrac{1}{2}(z-y)^{2}=\tfrac{1}{2}(7-10)^{2}=4.5$$

前向传播得到的是**每个节点的数值**，最终得到损失 $L$，即预测值与标签之间的差距。

## 3. 反向传播（backward propagation）

从损失出发（$\partial L/\partial L=1$），**沿箭头反方向**从右往左走，每到一个节点就用链式法则把梯度传给它的输入：

| 步骤 | 计算关系 | 结果 |
| --- | --- | --- |
| ① | $\dfrac{\partial L}{\partial z}=z-y=7-10$ | $-3$ |
| ② | $\dfrac{\partial L}{\partial u}=\dfrac{\partial L}{\partial z}\cdot\dfrac{\partial z}{\partial u}=(-3)\times 1$ | $-3$ |
| ③ | $\dfrac{\partial L}{\partial b}=\dfrac{\partial L}{\partial z}\cdot\dfrac{\partial z}{\partial b}=(-3)\times 1$ | $-3$ |
| ④ | $\dfrac{\partial L}{\partial w}=\dfrac{\partial L}{\partial u}\cdot\dfrac{\partial u}{\partial w}=(-3)\times x=(-3)\times 2$ | $-6$ |
| ⑤ | $\dfrac{\partial L}{\partial x}=\dfrac{\partial L}{\partial u}\cdot\dfrac{\partial u}{\partial x}=(-3)\times w=(-3)\times 3$ | $-9$ |
| ⑥ | $\dfrac{\partial L}{\partial y}=-(z-y)$ | $+3$ |

得到 $\partial L/\partial w=-6$、$\partial L/\partial b=-3$ 之后，就可以进入最后一步：参数更新。

## 4. 参数更新：权重与偏置的计算公式

反向传播求出梯度后，用**梯度下降**更新权重与偏置（两者规则完全相同，只是梯度不同）：

$$w_{\mathrm{new}}=w_{\mathrm{old}}-\eta\,\frac{\partial L}{\partial w},\qquad b_{\mathrm{new}}=b_{\mathrm{old}}-\eta\,\frac{\partial L}{\partial b}$$

符号说明：

| 符号 | 含义 |
| --- | --- |
| $w_{\mathrm{old}},\ b_{\mathrm{old}}$ | 更新前的权重与偏置 |
| $w_{\mathrm{new}},\ b_{\mathrm{new}}$ | 更新后的权重与偏置 |
| $\eta$ | 学习率（步长），决定一次更新走多远 |
| $\dfrac{\partial L}{\partial w},\ \dfrac{\partial L}{\partial b}$ | 反向传播算出的梯度 |

代入本例的数值（取学习率 $\eta=0.1$）：

$$w_{\mathrm{new}}=3-0.1\times(-6)=3.6,\qquad b_{\mathrm{new}}=1-0.1\times(-3)=1.3$$

三点理解：

- **为什么是「减」**：梯度指向损失上升最快的方向，减去它才是让损失下降最快的方向。
- **学习率决定步长**：太小收敛很慢，太大容易来回震荡甚至发散。
- **正负号的含义**：本例梯度为负，参数就增大（$w:3\to3.6$、$b:1\to1.3$）；若梯度为正，参数则减小。

更新之后再走一遍前向传播，可以检验这一步走对了没有：$z=3.6\times2+1.3=8.5$，$L=\frac{1}{2}(8.5-10)^{2}=1.125$，比更新前的 $4.5$ 明显变小——参数确实朝着让损失下降的方向移动了。

> 一次「前向传播 → 反向传播 → 参数更新」称为一个训练步（iteration）；反复迭代很多次，就是模型的训练过程。

## 5. 两条好记的规律

- **加法节点**：上游梯度**原样分发**给每个输入（$\partial z/\partial u=\partial z/\partial b=1$）。
- **乘法节点**：上游梯度**交换着传**（$\partial u/\partial w=x$，$\partial u/\partial x=w$）。

## 6. 前向与反向的对比

| 对比项 | 前向传播 | 反向传播 |
| --- | --- | --- |
| 方向 | 输入 → 输出（从左到右） | 损失 → 输入（从右到左） |
| 算什么 | 每个节点的数值 | 每个节点对损失的梯度 |
| 依据 | 节点自身的运算 | 链式法则 + 局部导数 |
| 用途 | 算出预测值与损失 | 得到梯度，交给优化器更新参数 |

一句话：**前向传播算值，反向传播算梯度**；一次前向加一次反向，就完成了一轮参数更新的准备。

## 7. 二分类：概率的综合表示，以及为什么要取对数

### 一个式子同时表示两种情况

二分类中模型输出的是"$y=1$"的概率，记作 $\hat{y}=P(y=1\mid x)$，于是

$$P(y=0\mid x)=1-\hat{y}$$

把这两种情况的概率**合并写成一个式子**：

$$P(y\mid x)=\hat{y}^{\,y}\,(1-\hat{y})^{\,1-y},\qquad y\in\{0,1\}$$

验证一下，指数 $y$ 与 $1-y$ 起了"开关"作用：

| 真实标签 | 代入后 | 含义 |
| --- | --- | --- |
| $y=1$ | $\hat{y}^{1}(1-\hat{y})^{0}=\hat{y}$ | 只留下第一项，即"预测为 1"的概率 |
| $y=0$ | $\hat{y}^{0}(1-\hat{y})^{1}=1-\hat{y}$ | 只留下第二项，即"预测为 0"的概率 |

关键点：**0 次方恒等于 1**，所以另一个因式会自动消失。这样一个式子就把两种类别情况全部覆盖了，不必分类讨论。也正因为如此，它才是"对 $y$ 的概率的综合表示"。

若 $N$ 个样本相互独立，整个数据集的**似然函数**就是各样本概率的连乘：

$$L(\theta)=\prod_{i=1}^{N}\hat{y}_i^{\,y_i}\,(1-\hat{y}_i)^{\,1-y_i}$$

最大似然估计（MLE）就是找让 $L(\theta)$ 最大的参数，即 $\theta^*=\arg\max_\theta L(\theta)$。

### 为什么求最优解时要取对数

要求最大值时对目标取对数，关键靠两条性质：**单调性**（不改变最优解的位置）和**把乘除变成加减**（让计算与求导都变得简单）。具体有五点好处：

1. **不改变最优解**：$\ln$ 是单调递增函数，所以
   $$\arg\max_\theta L(\theta)=\arg\max_\theta \ln L(\theta)$$
   最大值点的位置完全一样。理论上任何单调递增函数都不改变最优解，但只有对数能把指数形式的似然"解掉"——所以选它。
2. **连乘变连加，避免数值下溢**：概率都落在 $(0,1)$，连乘时数值会急剧变小。1000 个 $0.01$ 相乘约为 $10^{-2000}$，直接超出浮点数范围变成 0（下溢），似然就彻底失真了。取对数后变成 1000 个数的**求和**：
   $$\ln L(\theta)=\sum_{i=1}^{N}\Big[y_i\ln\hat{y}_i+(1-y_i)\ln(1-\hat{y}_i)\Big]$$
3. **求导变得简单**：对数把指数搬下来变成普通系数——原来 $y$ 在指数上，取对数后就变成前置的乘数，梯度表达式非常简洁。
4. **优化性质好**：习惯写成最小化的**负对数似然**（也就是二元交叉熵）
   $$L=-\frac{1}{N}\sum_{i=1}^{N}\Big[y_i\ln\hat{y}_i+(1-y_i)\ln(1-\hat{y}_i)\Big]$$
   在逻辑回归这类模型中，它是参数的凸函数，只存在唯一全局最优，梯度下降可以稳定收敛；原始的连乘形式则没有这么好的优化性质，数值上也容易出问题。
5. **惩罚更合理**：当 $y=1$ 而 $\hat{y}\to 0$（模型"自信地答错"）时，$\ln\hat{y}\to-\infty$，损失趋于无穷大，对这种错误惩罚极重；而平方形式的损失对大错的惩罚只是平方级增长。

单样本损失 $-\big[y\ln\hat{y}+(1-y)\ln(1-\hat{y})\big]$ 的取值感受一下：

| 真实标签 $y$ | 预测 $\hat{y}$ | 损失 |
| --- | --- | --- |
| 1 | 0.9 | 0.105 |
| 1 | 0.5 | 0.693 |
| 1 | 0.1 | 2.303 |
| 0 | 0.1 | 0.105 |
| 0 | 0.9 | 2.303 |

答对且自信时损失很小，答错且自信时损失急剧变大——这正是我们希望优化器去避开的。

> 与前面的衔接：这个损失同样可以放进计算图里反向传播。若 $\hat{y}=\sigma(z)$（sigmoid 输出），则 $\dfrac{\partial L}{\partial z}=\hat{y}-y$，形式仍然是"预测值 − 真实值"；第 3 小点里平方损失的情形是 $\dfrac{\partial L}{\partial z}=z-y$，两者形状一致，这也是交叉熵配合 sigmoid 特别好用的原因。
