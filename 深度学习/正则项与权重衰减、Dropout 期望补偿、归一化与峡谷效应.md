# 正则项与权重衰减、Dropout 期望补偿、归一化与峡谷效应

创建日期：2026-10-13

## 0. 一句话概括

这三件事其实在回答同一个问题——**怎么让训练更稳、更容易收敛**：

- **正则项**：把参数往原点压，压缩网络的**有效容量**；在标准 SGD 下，它就等价于**权重衰减**；
- **Dropout**：让下一层的输入**同步缩水**，所以必须除以保留概率把**数学期望补回来**，才能让训练与推理的尺度一致；
- **归一化**：拉齐各方向的尺度，把狭长的"**独木舟**"优化曲面掰成圆润的"**大碗**"。

## 1. 正则项、压缩网络与权重衰减

### 1.1 从 L2 正则到权重衰减：一步步看

给目标函数加上 L2 正则项：

$$\tilde J(\theta)=J(\theta)+\frac{\lambda}{2}\lVert\theta\rVert_2^2$$

求梯度（正则项的梯度就是 $\lambda\theta$）：

$$\nabla_\theta\tilde J=\nabla_\theta J+\lambda\theta$$

按梯度下降更新参数：

$$\theta\leftarrow\theta-\eta\big(\nabla_\theta J+\lambda\theta\big)=\underbrace{(1-\eta\lambda)}_{\text{衰减因子}}\theta-\eta\nabla_\theta J$$

**看清这一步的含义**：每走一步，都**先把权重整体乘上一个略小于 1 的因子** $(1-\eta\lambda)$，然后再沿原来的梯度走一步。这就是"**权重衰减**"（weight decay）这个名字的来历——它并不是什么额外的操作，而是 L2 正则在更新式里的自然形态。

$$\boxed{\;\text{标准 SGD 下：L2 正则}\;\Longleftrightarrow\;\text{权重衰减}\;}$$

> **重要提醒：换成 Adam 就不等价了。**
> 在 Adam 这类**自适应**优化器里，L2 的 $\lambda\theta$ 会被塞进梯度，再被"按梯度二阶矩归一化"的自适应学习率缩放，结果衰减的效果被扭曲；而"真正的"权重衰减是**直接对参数做乘法**，不经过梯度。这就是 **AdamW** 的由来——它把权重衰减从梯度里拆出来单独做。所以现代实现里，这两个词已经被有意区分开了。

### 1.2 为什么说它"压缩"了网络

"压缩"不是说真的删掉参数，而是**把模型能表达的东西变少了**——降低**有效容量**（effective capacity）。可以从五个角度看：

| 视角 | 正则项在做什么 | 结果 |
| --- | --- | --- |
| 参数空间 | 把参数往原点拉 | 权重范数变小，搜索范围被限制在一个"小球"里 |
| 函数空间 | 惩罚大权重 ⇒ 惩罚陡峭的函数 | 模型被迫输出更**平滑**的函数，假设空间变小 |
| 几何/稳定性 | 权重范数小 ⇒ Lipschitz 常数小 | 输出对输入的微小扰动不敏感，泛化更稳 |
| 结构 | 一部分权重被压到接近 0 | 可以**剪枝**（pruning）得到更小、更稀疏的网络 |
| 贝叶斯 | L2 = 权重的高斯先验；L1 = 拉普拉斯先验 | L1 产生稀疏解（真的把权重压成 0），L2 只是"整体压缩" |

**一句话直觉**：过拟合的本质是模型"把训练集的噪声也背下来了"，而背噪声需要**很大的权重**和**很陡的函数**——这恰好正是正则项惩罚的对象。把这条路堵窄，模型就只好去学那些平滑、通用的规律。

### 1.3 L1、L2、早停的对比

| 正则 | 惩罚项 | 梯度里的效果 | 更新后是否稀疏 |
| --- | --- | --- | --- |
| L2（权重衰减） | $\dfrac{\lambda}{2}\lVert\theta\rVert_2^2$ | 每步把权重**按比例**缩小 | 否，权重整体趋小但不为 0 |
| L1 | $\lambda\lVert\theta\rVert_1$ | 每步减去一个**固定量** $\eta\lambda\,\mathrm{sign}(\theta)$ | 是，很多权重被压到**恰好 0** |
| 早停 | —— | 限制迭代步数 | 间接压缩：参数根本没机会长大 |

> **早停也是一种正则**：它把"参数能走多远"限制住了。在简单的二次近似下，早停的效果与 L2 正则相当——都是把参数约束在一个较小的范围内。

## 2. Dropout：输入同步减少与期望补偿

### 2.1 Dropout 在做什么

训练时，对某一层的输出 $h$ 逐元素乘一个**伯努利掩码**：

$$m_i\sim\mathrm{Bernoulli}(q),\qquad \tilde h_i=m_i\,h_i$$

即每个神经元以概率 $q$ **保留**、以概率 $1-q$ 被置零（$q$ 叫 keep probability，常取 0.5）。

### 2.2 不补偿会怎样：整层输入"同步缩水"

掩码 $m_i$ 是独立同分布的，所以**整层输出在期望意义上被同步地按 $q$ 缩小**：

$$\mathbb E[\tilde h_i]=q\,h_i$$

于是下一层的输入 $z=\sum_i w_i\tilde h_i$ 的期望也跟着缩水成 $q$ 倍：

$$\mathbb E[z]=q\sum_iw_ih_i=q\,w^{\mathrm T}h$$

**问题来了**：训练时每层的输入尺度都只有原值的 $q$ 倍，而**推理（测试）时不做 dropout、所有神经元都参与**——两边的数值尺度对不上，相当于网络的"有效权重"在训练和推理之间被偷偷改掉了。这就是必须做补偿的原因。

### 2.3 解决：除以保留概率，把期望补回来

训练时给**保留下来的**神经元除以 $q$：

$$\tilde h_i=\frac{m_i\,h_i}{q}\qquad\Longrightarrow\qquad \mathbb E[\tilde h_i]=\frac{q\,h_i}{q}=h_i$$

$$\boxed{\;\text{期望完全不变}\;}$$

于是**推理阶段什么都不用改**，直接原样前向传播即可，训练与推理的尺度天然一致。

| 做法 | 训练时 | 推理时 | 现状 |
| --- | --- | --- | --- |
| **Inverted dropout**（缩放放在训练） | $\tilde h=\dfrac{m\odot h}{q}$ | 原样使用 | ✅ 现代框架的默认做法 |
| 旧式（原论文） | $\tilde h=m\odot h$ | 权重乘 $q$，或输出乘 $q$ | 已淘汰：推理时要改网络，麻烦且易错 |

> **期望不变，方差不不变。** 缩放后的方差是
> $$\mathrm{Var}(\tilde h_i)=\mathbb E[\tilde h_i^2]-h_i^2=\frac{q\,h_i^2}{q^2}-h_i^2=\frac{1-q}{q}h_i^2$$
> 也就是说 dropout 往网络里注入了**乘性噪声**——这正是它像"训练了很多个子网络再平均"的原因。

### 2.4 保持期望的四点作用

1. **尺度一致**：训练与推理的前向数值处在同一量级，避免"训练时学到的权重到推理时被隐性缩小/放大"；
2. **学习率不被误导**：如果训练时激活只有 $q$ 倍，反向传播的梯度尺度也跟着变，等于在不知不觉中改了有效学习率；
3. **抑制共适应**（co-adaptation）：任何神经元都不能指望"搭档一定在场"，网络被迫学到**冗余、鲁棒**的特征；
4. **集成视角**：每采样一次掩码就得到一个子网络，dropout 训练近似于训练指数多个**共享权重**的子网络，推理时用"全网络"去近似这个集成的平均——而**期望补偿正是让"全网络"与"子网络平均"对齐的关键**。

### 2.5 实践要点

- $q$ 常取 0.5（隐藏层）、0.8～0.9（输入层）；
- **推理阶段必须关掉 dropout**（PyTorch 里是 `model.eval()`），否则每次预测结果都不一样；
- 与 Batch Norm 同用时要注意两者的相互影响：BN 依赖每批的统计量，而 dropout 会改变方差；
- 卷积层常用 SpatialDropout（整通道丢弃），而不是逐元素丢弃——逐元素丢弃会破坏卷积的局部相关性。

## 3. 归一化与峡谷效应：独木舟与大碗

### 3.1 什么是峡谷效应

如果损失函数的等高线是一个**狭长的椭圆**（像一条峡谷、或者一条独木舟），说明：

- 沿**短轴**（陡峭方向）曲率极大 → 这个方向的梯度几乎垂直于通往最优点的方向；
- 沿**长轴**（平缓方向）曲率极小 → 这个方向的梯度几乎没有分量，进展极慢。

梯度下降在这种曲面上会**在陡的方向来回横跳（zigzag），在平的方向爬得极慢**，收敛很慢；而且学习率不能取大——取大了在陡方向会直接发散。

定量地看，把 Hessian 的两个极端特征值记作 $\lambda_{\max}$、$\lambda_{\min}$，定义**条件数**

$$\kappa=\frac{\lambda_{\max}}{\lambda_{\min}}$$

$\kappa\approx1$ 时等高线是圆（大碗）；$\kappa\gg1$ 时就是狭长椭圆（独木舟）。梯度下降每步的误差收缩因子约为 $1-\frac{1}{\kappa}$，所以**$\kappa$ 越大，收敛越慢**。

### 3.2 独木舟模型 vs 大碗模型

![[图片库/独木舟与大碗-归一化与峡谷效应.png]]

*图 1　**左：独木舟（病态）**。条件数很大，等高线被拉成狭长的椭圆；梯度下降的路径是之字形——在陡的短轴方向来回震荡，在平的长轴方向几乎原地踏步（红点越往后越密）。**右：大碗（良态）**。条件数接近 1，等高线是同心圆，梯度方向大致就指向最优点，因此路径几乎是直线，步子也大得多。中间的箭头是归一化：它把"独木舟"掰回"大碗"。*

| 对比项 | 独木舟（峡谷 / 病态） | 大碗（良态） |
| --- | --- | --- |
| Hessian 条件数 | $\kappa\gg1$ | $\kappa\approx1$ |
| 等高线形状 | 狭长椭圆 | 同心圆 |
| 梯度方向 | 几乎垂直于最优方向 | 大致指向最优点 |
| 下降路径 | 之字形来回震荡，沿谷底慢慢爬 | 直奔中心 |
| 学习率 | 被最陡的方向卡死，只能取很小 | 可以取大得多 |
| 典型成因 | 各特征量纲/尺度差异大、参数强相关 | 各方向曲率相近 |

### 3.3 归一化为什么能把独木舟掰成大碗

**输入尺度的差异是病态的主要来源。** 设想两个特征：$x_1$ 的量纲是"米"，取值在 0.001 量级；$x_2$ 的量纲是"毫米"，取值在 1000 量级。同样的权重扰动，在 $x_2$ 方向上引起的损失变化是 $x_1$ 方向的百万倍——Hessian 的特征值自然相差百万倍，等高线就被拉成了一条独木舟。

**归一化做的正是把这些尺度拉齐：**

| 做法 | 做了什么 | 效果 |
| --- | --- | --- |
| 输入标准化（z-score） | $\hat x_i=\dfrac{x_i-\mu_i}{\sigma_i}$ | 各特征方差都变成 1，Hessian 对角元量级接近，$\kappa$ 大幅下降 |
| Batch Norm / Layer Norm | 把每层的激活分布标准化 | 在每一层前都做一次"尺度对齐"，让各层输入尺度稳定 |
| 白化（whitening） | 除方差外还**去相关** | 最强的做法，直接逼近"大碗" |

等高线从独木舟变成大碗之后：

| 效果 | 说明 |
| --- | --- |
| 收敛更快 | 梯度方向更接近指向最优，之字形消失 |
| 可以用更大学习率 | 不再被某个特别陡的方向限制 |
| 对初始化不敏感 | 不同初始尺度下的训练行为差别变小 |
| 梯度更可预测 | 各方向曲率接近，梯度方向随参数的变化更平滑 |

### 3.4 一个重要的现代结论

> Batch Norm 之所以有效，**主要并不是因为"减少了内部协变量偏移"**（这个解释后来被实验否定），而是因为它**让损失曲面更平滑**：梯度的 Lipschitz 常数变小、梯度方向更可预测，因此可以放心用大学习率。（Santurkar et al., *How Does Batch Normalization Help Optimization?*, 2018）

这正好呼应本节的主线：**归一化真正在改造的，是优化曲面的"形状"**——把病态的峡谷（独木舟）变成良态的圆碗。

### 3.5 边界与反面

- 归一化**不改变最优解本身**（对尺度不变的模型；对一般模型它改变的是参数化方式），它改变的是**优化的路径与难度**——"走得动"和"最优在哪"是两件事；
- 归一化不是万能的：小批量时 BN 的统计量噪声大，可能不稳定（于是有了 LayerNorm、GroupNorm）；对某些对绝对尺度敏感的任务（比如物理量回归），盲目标准化反而有害；
- 归一化与正则化是**互补**的两件事：**归一化改造优化曲面（让训练走得动），正则化限制模型容量（让模型不过拟合）**。

> 一句话：**正则项通过压缩有效容量抑制过拟合，而 L2 正则在标准 SGD 下就是权重衰减（Adam 下要用 AdamW 才能保持等价）；dropout 让下一层输入同步缩水，必须除以保留概率把期望补回来，训练与推理的尺度才一致；归一化则把各方向的曲率拉齐，把狭长的"独木舟"掰成圆润的"大碗"，让梯度下降走得又快又稳。**

## 4. 梯度检验：为什么要用"双边"近似

### 4.1 两种差商，误差差一个量级

要检查反向传播算出的梯度 $g_i=\frac{\partial J}{\partial\theta_i}$ 对不对，最直接的办法是用**数值差商**去逼近它。

**单边（前向）差商**：

$$\frac{J(\theta+\epsilon e_i)-J(\theta)}{\epsilon}=g_i+O(\epsilon)$$

**双边（中心）差商**：

$$\boxed{\;\frac{J(\theta+\epsilon e_i)-J(\theta-\epsilon e_i)}{2\epsilon}=g_i+O(\epsilon^2)\;}$$

**为什么双边的误差更小**——把两边各做泰勒展开（$e_i$ 是第 $i$ 个方向的单位向量）：

$$J(\theta+\epsilon e_i)=J+\epsilon g_i+\frac{\epsilon^2}{2}H_{ii}+\frac{\epsilon^3}{6}J'''+\cdots$$

$$J(\theta-\epsilon e_i)=J-\epsilon g_i+\frac{\epsilon^2}{2}H_{ii}-\frac{\epsilon^3}{6}J'''+\cdots$$

相减时：**常数项和 $\epsilon^2$ 项都抵消了**，剩下 $2\epsilon g_i+\frac{\epsilon^3}{3}J'''+\cdots$，除以 $2\epsilon$ 得 $g_i+O(\epsilon^2)$。而单边差商只消掉了常数项，$\epsilon$ 的一次项误差保留了下来。

**量级上的差别**：取 $\epsilon=10^{-4}$，单边误差约 $10^{-4}$，双边误差约 $10^{-8}$——**整整差四个数量级**。

### 4.2 检验的做法与阈值

$$\text{相对误差}=\frac{\lVert d\theta_{\text{approx}}-d\theta\rVert_2}{\lVert d\theta_{\text{approx}}\rVert_2+\lVert d\theta\rVert_2}$$

| 相对误差 | 判断 |
| --- | --- |
| 约 $10^{-7}$ | 很好，梯度实现基本没问题 |
| 约 $10^{-5}$ | 要警惕，存在能修的错误 |
| 约 $10^{-3}$ | 基本可以确定实现有问题 |

**四个注意事项**：

- 只在**调试**时用：每一维都要多算两次前向传播，$n$ 个参数要 $2n$ 次，训练时不可能用；
- **关闭 dropout**（以及任何随机性）后再检验，否则同一个 $\theta$ 两次前向结果不同，差商完全失真；
- 如果损失里带正则项，**要把正则项的梯度一并算进去**再比较，否则差的正是那一项；
- $\epsilon$ 不能太大（截断误差）也不能太小（浮点舍入误差，$\epsilon\sim10^{-7}$ 时相减会出现灾难性抵消），$10^{-4}\sim10^{-6}$ 是常用区间。

## 5. 指数加权平均：$V_t$、$1/e$ 阈值与偏差修正

### 5.1 递推式与它的展开

$$V_t=\beta V_{t-1}+(1-\beta)\theta_t,\qquad V_0=0$$

把递推一层层展开：

$$V_t=(1-\beta)\theta_t+(1-\beta)\beta\theta_{t-1}+(1-\beta)\beta^2\theta_{t-2}+\cdots=(1-\beta)\sum_{i=1}^{t}\beta^{\,t-i}\theta_i$$

**含义**：$V_t$ 是历史数据的加权平均，**越近的项权重越大，越远的项权重按几何级数 $\beta^k$ 衰减**。它有两个工程上的好处：内存只要 $O(1)$（只保存一个 $V$，不需要存最近 $N$ 个数），每步只要一次乘加。

> 注意：所有权重加起来是 $1-\beta^t$，**不是 1**——这就是下面偏差的根源。

### 5.2 为什么 $1/e$ 决定了"显著与否"的阈值

把 $\beta^k$ 看作"前 $k$ 步那一项相对最新项的权重占比"。因为 $\beta$ 接近 1 时有 $\ln\beta\approx-(1-\beta)$，所以

$$\beta^{k}=\mathrm e^{\,k\ln\beta}\approx \mathrm e^{-(1-\beta)k}$$

令它等于 $1/\mathrm e$：

$$\mathrm e^{-(1-\beta)k}=\mathrm e^{-1}\;\Longrightarrow\;\boxed{\;k=\frac{1}{1-\beta}\;}$$

**含义**：往前推 $1/(1-\beta)$ 步，那一项的权重已经衰减到**不足最新项的 $1/\mathrm e\approx36.8\%$**；再往前的项影响更小，可以视为"**不显著**"。于是

$$\text{有效窗口长度}\approx\frac{1}{1-\beta}$$

| $\beta$ | $1/(1-\beta)$ | 有效窗口 |
| --- | --- | --- |
| 0.5 | 2 | 只看最近两三项 |
| 0.9 | 10 | 最近 10 步 |
| 0.98 | **50** | 最近 50 步 |
| 0.99 | 100 | 最近 100 步 |

$\beta$ 越大曲线越平滑但越"迟钝"——本质就是窗口被拉长了。

### 5.3 为什么要除以 $1-\beta^t$：偏差修正

**偏差从哪来**：$V_0$ 被初始化成 0，等于凭空塞进了一个"等于 0 的历史值"，把整个序列往下拉。看一个最干净的情形——设 $\theta$ 恒等于常数 $c$，则上式的期望是

$$\mathbb E[V_t]=c\,(1-\beta)\sum_{i=1}^{t}\beta^{\,t-i}=c\,(1-\beta^t)$$

**整整少了 $1-\beta^t$ 倍**！于是只要除以它：

$$V_t^{\text{corr}}=\frac{V_t}{1-\beta^t}\qquad\Longrightarrow\qquad \mathbb E\big[V_t^{\text{corr}}\big]=c\quad\checkmark$$

**无偏**。偏差的大小就是 $\beta^t$ 本身：

| $t$ 与窗口 $1/(1-\beta)$ 的关系 | $\beta^t$ | 不修正时的相对偏差 |
| --- | --- | --- |
| $t=\dfrac{1}{1-\beta}$ | $\approx\dfrac{1}{\mathrm e}=0.368$ | **36.8%**，很大，必须修正 |
| $t=\dfrac{3}{1-\beta}$ | $\approx\mathrm e^{-3}=0.05$ | 5%，仍有影响 |
| $t\gg\dfrac{1}{1-\beta}$ | $\to0$ | 可忽略，很多实现干脆省掉 |

**回到"50 个及以上为什么还要除"这个问题**——

关键在于**"50 个"这个数字要和窗口长度比，而不是和"数据条数"比**：

- 若 $\beta=0.98$，窗口 $1/(1-\beta)$ **正好是 50**。在 $t=50$ 时 $\beta^{50}=0.98^{50}\approx0.364$，**偏差还有 36%**；不修正的话 $V_{50}$ 只有真实加权平均的 $1-\beta^{50}=0.636$ 倍，**除以 $1-\beta^t$ 相当于把结果放大约 1.57 倍**——修正不但必要，而且影响很大。要等到 $t$ 约为窗口的三倍（150 个点）时，$\beta^t$ 才降到 5% 左右，修正才开始变得可有可无；
- 反过来，若 $\beta=0.9$（窗口只有 10），那么 50 个点已经是 5 倍窗口，$\beta^{50}=0.9^{50}\approx0.005$，修正因子 $1-\beta^t\approx0.995$，只有 0.5% 的影响，这时确实可以省略。

> **判断标准不是"有多少条数据"，而是 $t$ 相对窗口 $1/(1-\beta)$ 有多大**：$t$ 在窗口量级之内，必须除以 $1-\beta^t$；$t$ 远超窗口，才可以省。

*图 2　**左**：以 $\beta=0.9$ 为例的权重 $\beta^k$。柱子越往右越矮，说明越久远的数据影响越小；红色虚线是 $1/\mathrm e\approx0.37$ 这条"显著线"，第 10 根柱子（$k=1/(1-\beta)=10$）正好降到它下面——这就是"有效窗口 = 10 步"的可视化。**右**：偏差修正的效果。横轴是步数 $t$，假设真值恒为 1：灰色虚线是**未修正**的 $V_t=1-\beta^t$，从 0 开始慢慢往上爬，到 $t=10$（红虚线）时还只有 0.65，偏差 36%；蓝色实线是**修正后**的 $V_t/(1-\beta^t)$，从一开始就等于真值。*

### 5.4 指数加权平均用在哪里

| 应用 | 被平滑的对象 | 作用 |
| --- | --- | --- |
| 动量法 Momentum | 梯度 $dw$、$db$ | 抑制梯度来回震荡，沿"峡谷"方向加速——正好对应第 3 节的独木舟问题 |
| RMSProp | 梯度平方 $(dw)^2$ | 估计各方向的梯度尺度，自适应缩放学习率 |
| **Adam** | 一阶矩 + 二阶矩，**都带偏差修正** | 两者结合，是现代默认优化器 |
| 训练曲线的读取 | 损失、准确率 | 原始曲线噪声大，平滑后才看得清趋势 |
| 工程时序指标 | 温度、点击率、负载 | 用 $O(1)$ 内存与 $O(1)$ 计算维护滑动平均 |

> Adam 里偏差修正的作用最直观：$m_t$、$v_t$ 都从 0 出发，训练**初期**不修正会让更新量被严重低估（相当于"热身不足、步子太小"），所以 Adam 用的是
> $$\hat m_t=\frac{m_t}{1-\beta_1^{\,t}},\qquad \hat v_t=\frac{v_t}{1-\beta_2^{\,t}}$$
> 而且因为 $\beta_2$ 通常取 0.999（窗口 1000 步），这个修正要持续很久才衰减掉。

> 一句话：**指数加权平均用一个 $O(1)$ 的递推式实现了"越近权重越大"的平滑，权重按 $\beta^k$ 衰减、在 $k=1/(1-\beta)$ 处跌破 $1/\mathrm e$，所以 $1/(1-\beta)$ 就是有效窗口；但 $V_0=0$ 会给前期带来 $\beta^t$ 倍的系统性低估，必须除以 $1-\beta^t$ 才无偏——在 $t$ 还没远超窗口之前（例如 $\beta=0.98$ 时的前 50 个点），这个除法是万万省不得的。**
